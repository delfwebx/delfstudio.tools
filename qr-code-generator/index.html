Why these codes keep working

Many QR services route your code through their own website, so they can count scans and, later, switch the code off unless you pay. The codes made here hold your link or details directly. There is no middleman, so there is nothing that can expire, be limited or be taken down.

The trade-off is that a printed code cannot be changed afterwards and there are no scan statistics. If your link might change, point the code at a page you control and update that page instead.

Before you print

  • Scan the code with your own phone first, from the distance people will really use.
  • Keep the code dark and the background light. That is what phone cameras read best.
  • Leave the blank border around the code. Scanners need it.
  • Print it at least 2 cm wide, and larger for posters people scan from further away.
  • Use the SVG file for print work. It stays sharp at any size.

Questions people ask

Do the QR codes expire?

No. Your content is stored inside the code itself, so it works for as long as the link or details it holds stay valid.

Is it free for business use?

Yes. Use the codes on menus, packaging, flyers, business cards or anywhere else, with no charge and no attribution.

Can I change where the code goes after printing?

No. These are static codes, so the content is fixed once made. If you need a different link, make a new code.

Can I see how many people scanned it?

Not from here, because scans do not pass through any server of ours. To count visits, link to a page on your own site and check that page in your website analytics.

How does the Wi-Fi code work?

Guests point their phone camera at the code and tap the prompt to join your network, without typing the password. It works on current iPhones and Android phones.

Will a logo stop the code from scanning?

It should not. When you add a logo, the code is made with the highest level of error correction, which lets scanners read it even with the middle covered. Always test it before printing.

Is my information private?

Yes. The code is drawn by your own browser. Your links, passwords and contact details are never sent to us or stored.
